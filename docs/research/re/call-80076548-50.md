# Arrival 50 at 0x80076548

Traced fact from the USA PS-X EXE. Re-check on a disc you own with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x80076548`. The executable and the listing stay in `build/`.

The start address is `0x80076548`. The `jal` in [call-80076548-49.md](call-80076548-49.md) returns here. `a0` was `0x2e`. The byte at `0x800b5e87` is `0x10`, so bit 0 is clear and `v0` stays `0x2e`. The word at `0x800b5c14` is `0x98d3`. `s2` becomes `0x0134e4d0`. `s0` becomes 9. The next byte is `0x39`.

`jal` at `0x80076540` calls `tolower` with `a0` `0x39`. This note does not enter `tolower`. The return is the next note.
