# Call at 0x80018b64

[call-80036278.md](call-80036278.md) reaches this address. `a0` is that caller's pointer plus `0x34`. The pointer's number is not stated. `ra` is `0x80036288`. `a1`, `a2`, and `a3` are not stated.

`addiu` writes 3 into `v0`. `sw` stores `a2` at `a0+0x30`, `a1` at `a0+0x34`, and `a3` at `a0+0x38`. `jr` returns 3. The delay slot stores 3 at `a0+0x8`.

The 24 bytes from `0x80018b64` through `0x80018b78` occur once.

## Our code

`call_80018b64` writes those four words and returns 3. The host check uses a local object.

## Gap

This boot does not state `a1`, `a2`, or `a3`.
