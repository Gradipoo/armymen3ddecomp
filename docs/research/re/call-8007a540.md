# Block at 0x8007a540

Traced fact from the USA PS-X EXE. Re-check on a disc you own with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x8007a540`. The executable and the listing stay in `build/`.

The start address is `0x8007a540`. The `jal` in [call-8007a65c.md](call-8007a65c.md) jumps here. That `jal` at `0x8007a660` sets `ra` to `0x8007a668`. The caller's `ra`, `0x800252ac`, stays in the frame at `0x8007a628`. Which path reached the `jal` at `0x8002525c` is still unknown. The tool followed 11 instructions and stopped at the first branch. The hard cap is 64 instructions. This block ended before the cap. The branch goes forward to `0x8007a604`, so this block is not a loop. The delay slot is the next word, at `0x8007a56c`. Re-check it with `--start 0x8007a56c`. That run's first instruction is the `sw`. The words after that instruction are not traced.

The words from `0x80010000` through `0x8001007c` are not read here. `0x80010000` is below `0x8001007c`, so `v0` is 1 and this boot does not take the branch.
