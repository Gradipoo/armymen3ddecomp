# Second return at 0x8005c224

Traced fact from the USA PS-X EXE, plus one PCSX-Redux capture. Re-check the instructions with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x8005c224`. The executable and the capture stay in `build/`.

The start address is `0x8005c224`. This is the second hit of `CdRead`'s return during the USA fast boot. `s0` is 0. `s1` is `0x800e54e0`. The saved `ra` is `0x8005c5e8`. The second line is in `build/research/behavior/cdread-8005c224-2-5501.jsonl`. `v0` is 1. The BIOS file is `build/bios/scph5501.bin`, reported as hash `8d8cb7e4`.

`sltiu` at `0x8005c224` leaves `v0` at 0. `bne` at `0x8005c228` is not taken. The delay slot clears `a0`. `jal` at `0x8005c230` targets `0x800840a8`. `tools/sdk_names.txt` names that address `CdReadSync`. `ra` becomes `0x8005c238`. The delay slot copies `a0` into `a1`, so `a1` is 0. This note does not enter that body. The return is in [call-8005c238-2.md](call-8005c238-2.md).
