# Arrival 3 at 0x80076548

Traced fact from the USA PS-X EXE. Re-check on a disc you own with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x80076548`. The executable and the listing stay in `build/`.

The start address is `0x80076548`. The `jal` in [call-80076548-2.md](call-80076548-2.md) returns here from `tolower`. `a0` was `0x4f`. The byte at `0x800b5ea8` has bit 0 set, so `tolower` adds `0x20`. `v0` is `0x6f`. `s3` is `0x800b5bf4`. The earlier notes at this address stay.

The word at `0x800b5bf8` is `0x30acb`. The low word of the product is added into `s2`, so `s2` becomes `0xbc3c4708`. `s0` becomes 2. That is below `0x1f`, so `bne` at `0x80076568` is taken. The next byte is `0x50`. `jal` at `0x80076540` calls `tolower` with that byte. This note does not enter `tolower`. The return is in [call-80076548-4.md](call-80076548-4.md).
