# Call at 0x80065638

No traced entry reaches this address. `lw` reads `0x800dd730`. That address is inside the zero fill in [entry-after-fill.md](entry-after-fill.md). No traced note stores it before this load, so the word is 0. `addiu` subtracts 4. `jr ra` returns 0 because `0xfffffffc` is not below 2. The arriving `ra` is not stated.

The 24 bytes from `0x80065638` through `0x8006564c` occur once.

## Our code

`call_80065638` returns 1 when the word minus 4 is below 2. The host check starts at 0 and expects 0.
