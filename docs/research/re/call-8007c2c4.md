# Call at 0x8007c2c4

No traced entry reaches this address. `v0` becomes `0x800e18b8`. `lw` reads `0x800e18c0` and `0x800e18bc`. Both addresses are inside the zero fill in [entry-after-fill.md](entry-after-fill.md). No traced note stores them, so both words are 0. `jr ra` returns their difference, which is 0. The arriving `ra` is not stated.

The 24 bytes from `0x8007c2c4` through `0x8007c2d8` occur once.

## Our code

`call_8007c2c4` returns the first word minus the second. The host check expects 0.
