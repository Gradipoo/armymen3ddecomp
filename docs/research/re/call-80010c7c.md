# Call at 0x80010c7c

[call-80010fdc.md](call-80010fdc.md) reaches this address and does not enter it. `a0` is the object pointer from that caller. This note also covers the same body when [call-80012e94.md](call-80012e94.md) calls it. `sw` writes 0 at `a0+0x6c` and `a0+0x74`. `sh` writes 0 at `a0+0x70` and `a0+0x72`. `jr ra` does not write `v0`. The arriving `ra` depends on the caller.

The 16 bytes from `0x80010c7c` through `0x80010c88` occur once.

## Our code

`call_80010c7c` clears those four fields. The host check starts them at 1 and expects 0.

## Gap

The arriving `v0` is not written here.
