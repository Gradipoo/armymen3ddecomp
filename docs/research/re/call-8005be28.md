# Call at 0x8005be28

[call-80074144.md](call-80074144.md) calls here. `a0` is 0. `ra` is `0x80074174`. This boot does not reach this address.

`v1` becomes `0x800d89b8`. `lw` at `0x8005be30` loads `0x800d89c0`. That address is inside the zero fill in [entry-after-fill.md](entry-after-fill.md). No traced note stores it, so `v0` is 0. `jr ra` returns to `0x80074174`. The delay stores `a0` at `0x800d89c0`, so that word becomes 0.

The 20 bytes from `0x8005be28` through `0x8005be38` occur once. The same five instructions with offsets `0xc` and `0x10` are the later notes at `0x8005be3c` and `0x8005be50`.

## Our code

`call_8005be28` returns the old word and stores `a0`. The host check starts from 0 and stores 0.
