# Call at 0x80010e00

Traced fact from the USA PS-X EXE. Re-check on a disc you own with
`python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x80010e00`.
The executable and the listing stay in `build/`.

The start address is `0x80010e00`. This is the function entry. The tool
follows straight-line words until the first jump. It followed 8
instructions and stopped at the `jal`. The hard cap is 64 instructions.
This block ended before the cap. The delay slot is the next word, at
`0x80010e20`. Re-check it with `--start 0x80010e20`. That run's first
instruction is the `addu`. This note covers those 9 instructions.

`addiu` at `0x80010e00` subtracts `0x18` from `sp`.

`lui` at `0x80010e04` loads `0x800a` into `a0`, so `a0` is `0x800a0000`.

`lui` at `0x80010e08` loads `0x8001` into `a2`, so `a2` is `0x80010000`.

`addiu` at `0x80010e0c` adds `-0xc98` to `a0`, so `a0` is `0x8009f368`.

`addiu` at `0x80010e10` sets `a1` to `0x1`.

`addiu` at `0x80010e14` adds `0xdb0` to `a2`, so `a2` is `0x80010db0`.

`sw` at `0x80010e18` stores the arriving `ra` at `0x10(sp)`.

`jal` at `0x80010e1c` targets `0x8007a384` and sets `ra` to `0x80010e24`.
The delay slot at `0x80010e20` is `addu a3, zero, zero`, so `a3` is 0.
`python3 tools/sdk_match.py` has no name for `0x8007a384`. The BIOS table
in [bios.md](bios.md) has no name for it. This note stops at the call and
its delay slot. The next address is `0x8007a384`.

These words write `sp`, `a0`, `a1`, `a2`, `a3`, `ra`, and the stack slot
at `0x10(sp)`. They read the arriving `ra` and `sp`. They do not read the
arriving `a0`, `a1`, `a2`, or `a3`. The word at `0x8009f368` is not quoted.
The body at `0x80010db0` is not entered. The words at `0x80010e24` are not
traced.

## Our code

`components/exe/call_80010e00.cpp` prepares those four arguments and calls
the supplied function. The retail target is `0x8007a384`. That body stays
a gap in the file. A host check records the values `0x8009f368`, `1`,
`0x80010db0`, and `0`. The check uses a local function. It does not run
the retail callee.
