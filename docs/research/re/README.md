| [call-8002523c.md](call-8002523c.md) | Paths at `0x8002523c` and `0x8002524c`. The non-zero path adds `0x1400` to the word at `0x8007f9d0` and falls into `0x8002524c`. Both paths call `0x8007f920` with `a0` `0x8009f820`, `a1` 0, and `a2` `0x9a4`. `ra` becomes `0x80025264`. Which path this boot takes is unknown. The callee's first block is in [call-8007f920.md](call-8007f920.md). |
| [call-8007f920.md](call-8007f920.md) | First block at `0x8007f920`. It branches to `0x8007f9a0` when `a0` is 0. This call's `a0` is `0x8009f820`, so the branch is not taken. | [call-8007f928.md](call-8007f928.md) | Block at `0x8007f928`. It branches to `0x8007f9a0` when `a2` is 0. This call's `a2` is `0x9a4`, so the branch is not taken. The delay slot sets `t0` to `0x7`. Control continues at `0x8007f930`. That block is in [call-8007f930.md](call-8007f930.md). |
| [call-8007f930.md](call-8007f930.md) | Block at `0x8007f930`. `slt` compares `t0` with `a2`. This call's `t0` is `0x7` and `a2` is `0x9a4`, so the `beq` to `0x8007f990` is not taken. The delay slot writes the low two bits of `a0` into `t0`. Control continues at `0x8007f93c`. That block is in [call-8007f93c.md](call-8007f93c.md). |
| [call-8007f93c.md](call-8007f93c.md) | Block at `0x8007f93c`. `beq` compares `t0` with zero. This call's `t0` is 0, so the branch to `0x8007f95c` is taken. The delay slot sets `t1` to `0x4`. Control continues at `0x8007f95c`. That block is in [call-8007f95c.md](call-8007f95c.md). |
| [call-8007f95c.md](call-8007f95c.md) | Block at `0x8007f95c`. It copies the low byte of `a1` across the word, then stores that word in a loop from `a0`. This call's `a1` is 0 and `a2` is `0x9a4`, so `t0` starts at `0x269` and the fill word is 0. The `bne` returns to `0x8007f978` until `t0` is 0. The delay slot adds 4 to `a0`. Control then continues at `0x8007f988`. That block is in [call-8007f988.md](call-8007f988.md). |
| [call-8007f988.md](call-8007f988.md) | Block at `0x8007f988`. `beq` compares `a2` with zero. This call arrives with `a0` at `0x800a01c4`, `t0` at 0, and `a2` at 0, so the branch to `0x8007f9a0` is taken. The delay slot is `nop`. Control continues at `0x8007f9a0`. That block is in [call-8007f9a0.md](call-8007f9a0.md). |
| [call-8007f9a0.md](call-8007f9a0.md) | Block at `0x8007f9a0` on the arrival from `0x8007f988`. `jr` returns through `ra`. `v0` stays `0x8009f820`. The delay slot is `nop`. `ra` stays `0x80025264`, so control goes there. That block is in [call-80025264.md](call-80025264.md). |
| [call-80025264.md](call-80025264.md) | Block at `0x80025264` after the return from `0x8007f9a0`. It replaces `v0` with `0x800b5c9c` and stores seven words through that base. It loads the word at `0x8007f9a8` into `a0` and calls `0x8007a628`. The delay slot stores `a0` at `0x8009f850`. The word at `0x8007f9d0` is not read. The callee's first block is in [call-8007a628.md](call-8007a628.md). |
| [call-8007a628.md](call-8007a628.md) | First block at `0x8007a628`. It saves `ra`, `s2`, `s1`, and `s0`, then compares the words at `0x8007f9b0` and `0x8007f9b4`. `beq` goes to `0x8007a6cc` when the unsigned compare is false, and falls through to `0x8007a65c` when it is true. The delay slot sets `s1` to `0x1`. `a0` stays the word from `0x8007f9a8`. Whether that word is 0 is still unknown, and this branch does not test it. The words are `0x80010000` and `0x8001007c`, so this boot takes `0x8007a65c`. That block is in [call-8007a65c.md](call-8007a65c.md). |
| [call-8007a65c.md](call-8007a65c.md) | Block at `0x8007a65c` after the compare at `0x8007a654`. The word at `0x8007f9b0` is `0x80010000` and the word at `0x8007f9b4` is `0x8001007c`, so the `beq` to `0x8007a6cc` is not taken. It copies those words into `a0` and `a1` and calls `0x8007a540`. The delay slot copies `s2` into `a1`. The callee's first block is in [call-8007a540.md](call-8007a540.md). |
| [call-8007a540.md](call-8007a540.md) | First block at `0x8007a540`. It saves `s2`, `s4`, `s3`, `ra`, `s1`, and `s0`, copies `a0` into `s2` and `a1` into `s4`, and sets `s3` to 0. `a0` is `0x80010000` and `a1` is `0x8001007c`, so `sltu` sets `v0` to 1 and the `beq` to `0x8007a604` is not taken. The delay slot saves `s0`. Control continues at `0x8007a570`. That block is in [call-8007a570.md](call-8007a570.md). |
| [call-8007a570.md](call-8007a570.md) | Block at `0x8007a570` after the compare at `0x8007a568`. `s2` is `0x80010000`. It loads the word at `s2`, then the word at offset `0xc` of that value, then the word at that address. `beq` goes to `0x8007a5e0` when the last word is 0, and falls through to `0x8007a590` when it is not. The delay slot sets `s1` to `0x1`. `s3` and `s4` are not used. The word at `0x80010000` is not quoted. Both bodies are not traced. |
