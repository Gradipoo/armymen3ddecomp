# Fallthrough at 0x80064e68

[call-80064e40.md](call-80064e40.md) stops at the unknown `beq` at
`0x80064e60`. [call-80064e58.md](call-80064e58.md) sampled `s2=2` at that
branch, so those samples fall through here. The same capture measured the
live destination `v0=0x80064f14` for index two. This note does not read
the table word from the executable file.

`python3 tools/boot_slice.py build/disc/SLUS_004.91 --start 0x80064e68 --max 64`
reports seven instructions and stops at `jr`. The report stays in `build/`.

On entry, `v0` already holds `0x800c0000` from the delay slot at
`0x80064e64`. `addiu` at `0x80064e68` adds `0x3e98`, so `v0` is
`0x800c3e98`. `sll` at `0x80064e6c` shifts `s2` left by two. `addu` at
`0x80064e70` adds that index to the table base. `lw` at `0x80064e74`
loads the word at that address into `v0`. `nop` at `0x80064e78` is the
load delay. `jr` at `0x80064e7c` jumps through `v0`. The delay slot at
`0x80064e80` is `nop`. The slice stops at `jr`. The target body is not
entered.

For the sampled index two, the word address is `0x800c3ea0`. The measured
destination `0x80064f14` is cited from [call-80064e58.md](call-80064e58.md).
The file image is not the live value of that word.

## Our code

`components/exe/call_80064e68.cpp` computes `0x800c3e98 + s2 * 4`. The
loaded pointer stays unstated unless a test injects the word.

`PadStateDispatchInject` in `call_80064e68.hpp` is test-only. Glue cites
index two from [call-80064e58.md](call-80064e58.md). Other indices use a
non-null `entry[s2]` in ctests and in `run_menu_input_scan_frames` when
passed through `menu_input_scan_step`.

| s2 | Word address | Destination |
| --- | --- | --- |
| 2 | `0x800c3ea0` | `0x80064f14` (measured, call-80064e58.md) |
| 3 | `0x800c3ea4` | gap live RAM; provisional `0x80064f14` only via test inject for Down/SDL mapping |
| 0, 1, 4, 5, 6 | `0x800c3e98 + s2*4` | gap; no live table word cited |

Index three is provisional for host Down mapping ([menu-scan-pad-sdl.md](menu-scan-pad-sdl.md)).
Retail captures kept `s2=2` while selection moved. The test inject does not
state the live word at `0x800c3ea4`.

## Gap

`jr v0` is not followed. Live table words stay unstated except index two.
Indices 0, 1, 4, 5, and 6 have no inject default. Index three has no retail
destination word. The sampled index-two destination is described in
[call-80064e58.md](call-80064e58.md), which stops at the unknown branch at
`0x80064f1c`.
