# First VSync at 0x8005c1e8

Traced fact from the USA PS-X EXE, plus one PCSX-Redux capture. Re-check the instructions with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x8005c1e8`. The executable and the capture stay in `build/`.

The start address is `0x8005c1e8`. The `jr` in [call-800818cc-2.md](call-800818cc-2.md) returns here. `s0` is 1. `s1` is `0x800e54e0`. The saved `ra` is `0x8005c804`. PCSX-Redux, interpreter, fast boot, the USA cue, and BIOS file `build/bios/scph5501.bin` hit this address once. The line is in `build/research/behavior/stat-800b5fcc-5501.jsonl`. `v0` is 0. The word at `0x800b5fcc` is `0x200`, so the loaded byte is 0. The emulator reports that BIOS file as hash `8d8cb7e4`, labeled SCPH-7003 (US).

`andi` at `0x8005c1e8` keeps bit `0x80`. `v0` stays 0. `bne` at `0x8005c1ec` is not taken. The delay slot copies `s0` into `a0`, so `a0` becomes 1. `jal` at `0x8005c1f4` targets `0x8008549c`. `tools/sdk_names.txt` names that address `VSync`. `ra` becomes `0x8005c1fc`. The delay slot clears `a0`. This note does not enter that body. The return is the next note.
