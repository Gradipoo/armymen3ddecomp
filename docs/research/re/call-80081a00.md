# Call at 0x80081a00

[call-8005bef8.md](call-8005bef8.md) does not reach this address. The other side of its `beq` would call here. `a0` and `a1` are not stated.

`jal` at `0x80081a08` targets `0x800825a8`. [call-800825a8.md](call-800825a8.md) names that body. `ra` is `0x80081a10`. The delay is `nop`. That body stops on the `VSync` compare, so `v0` is not stated. This note does not enter that body again.

The epilogue reloads `ra`. This note does not state the arriving value. `jr ra` leaves that `v0`.

The 32 bytes from `0x80081a00` through `0x80081a1c` occur once.

## Our code

`call_80081a00` calls `call_800825a8`. The host check only calls the function.
