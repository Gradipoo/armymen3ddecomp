# Call at 0x800655e4

No traced entry reaches this address. `lw` reads `0x800dd730`. That address is inside the zero fill in [entry-after-fill.md](entry-after-fill.md). No traced note stores it before this load, so the word is 0. `addiu` subtracts 1. `jr ra` returns 0 because `0xffffffff` is not below 2. The arriving `ra` is not stated.

The 24 bytes from `0x800655e4` through `0x800655f8` occur once.

## Our code

`call_800655e4` returns 1 when the word minus 1 is below 2. The host check starts at 0 and expects 0.
