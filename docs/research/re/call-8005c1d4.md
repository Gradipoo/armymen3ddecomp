# Call at 0x8005c1d4

Traced fact from the USA PS-X EXE, plus one PCSX-Redux capture. Re-check the instructions with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x8005c1d4`. The executable and the capture stay in `build/`.

The start address is `0x8005c1d4`. `CdControlB` returns here. `s0` is 1. `s1` is `0x800e54e0`. The saved `ra` is `0x8005c804`. PCSX-Redux, interpreter, fast boot, the USA cue, and BIOS file `build/bios/scph5501.bin` hit this address once. The line is in `build/research/behavior/cdcontrolb-8005c1d4-5501.jsonl`. `v0` is 1. The emulator reports that BIOS file as hash `8d8cb7e4`, labeled SCPH-7003 (US).

`sltiu` at `0x8005c1d4` compares that 1 with 1, so `v0` becomes 0. `bne` at `0x8005c1d8` is not taken. The delay slot is `nop`. `jal` at `0x8005c1e0` targets `0x800818cc`. `ra` becomes `0x8005c1e8`. The delay slot is `nop`. `python3 tools/sdk_match.py` does not name `0x800818cc`. The next note is [call-800818cc-2.md](call-800818cc-2.md).
