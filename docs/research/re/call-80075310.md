[call-80075198-2.md](call-80075198-2.md), [call-80075198-5.md](call-80075198-5.md), [call-80075198-8.md](call-80075198-8.md), and [call-80075198-11.md](call-80075198-11.md) arrive with `a0` 4. Each one takes `beq` at `0x800751d0` because the word at `0x800e152c` is 0. This boot does not reach this address. No traced entry arrives with `a0` 7.

For the cited `a0` 4 entries, saved `ra` is `0x800624cc`, so `jr ra` would return there. The saved `s0` is not the same word in every entry. This note does not state it. This boot does not return 1.

The 8 bytes at `0x80075310` and `0x80075314` occur once.
