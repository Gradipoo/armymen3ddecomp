# Call at 0x80076414

Traced on the local USA executable. The previous return is described in
[call-800761dc.md](call-800761dc.md). Existing block notes stay as they are.

The instruction at `0x80076414` calls `0x80076274`. The delay slot copies
`s2` into `a0`. On this boot `s2` is zero, so the argument is zero. The
return address is `0x8007641c`. `s0` is 1 and `s1` is `0x800e0000`.
The incoming `v0` is not read by this call or its delay slot.

`python tools/sdk_match.py build/disc/SLUS_004.91` does not name the target.
This note stops at that unnamed call and its delay slot. The callee is
covered by [call-80076274.md](call-80076274.md).

Re-check the call with `tools/entry_disasm.py` at the start address. Re-check
the delay slot separately at `0x80076418`. Listings stay under `build/`.
