# Return after cursor 0x80010044

Traced fact from the USA PS-X EXE. Re-check on a disc you own with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x8007a5a4`. The executable and the listing stay in `build/`.

The start address is `0x8007a5a4`. The `jal` in [call-8007a540-18.md](call-8007a540-18.md) returns here through [call-8007a5a4-48.md](call-8007a5a4-48.md). `v0` is `0x800b5d78`. `s0` is `0x800b3b60`. `s1` is 1. `s2` is `0x80010044`. `s3` is 0. The frame at `0x800251f8` stays open. Its saved `ra` stays `0x8007faec`.

The return matches [call-8007a5a4-48.md](call-8007a5a4-48.md). Offset 8 is 0 and the next list word is 0, so `s2` becomes `0x80010048`. That value is below `s4`, so `beq` at `0x8007a5fc` is taken.

The live word at `0x80010048` is `0x800b599c`, from [call-8007a668-16.md](call-8007a668-16.md). Control goes to `0x8007a570` with `s2` at `0x80010048`. That lap is not traced. The caller return at `0x8007faec` is not traced.
