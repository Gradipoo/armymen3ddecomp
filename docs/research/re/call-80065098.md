# Taken target at 0x80065098

[call-8006508c.md](call-8006508c.md) records `bne` at `0x8006508c` when `s6`
is nonzero. The taken target is this address. The fallthrough at
`0x80065094` sets `v0` to one before the same store at `0x80065098`. The
`s6` nonzero path keeps `v0` at five from the delay slot at `0x80065090`.
This note covers only the `s6` nonzero entry where `v0` is five. It does
not resume the parked static boot.

`python3 tools/boot_slice.py build/disc/SLUS_004.91 --start 0x80065098 --max 64`
reports four instructions and stops at an unknown branch. The report stays
in `build/`.

| Address | Instruction |
| --- | --- |
| `0x80065098` | `sw v0, 0(s0)` |
| `0x8006509c` | `andi v0, a0, 0x80` |
| `0x800650a0` | `beq v0, zero, 0x800650b4` |
| `0x800650a4` | `addiu s1, s1, 0x4` |

The delay slot at `0x800650a4` always runs. `s1` advances by four before
the branch resolves. `a0` is complemented menu input from
[call-80064f48.md](call-80064f48.md). `s0` is the record base used in the
mask stores. Their live values on the `s6` nonzero path are not stated in
this slice.

`beq` at `0x800650a0` compares the `0x80` bit test with zero. The taken
address is `0x800650b4`. The fallthrough is `0x800650a8`. Static boot does
not state complemented input for a nonzero `s6` sample, so the branch side
is unknown for retail. Glue follows both targets in
[call-800650a8.md](call-800650a8.md) and [call-800650b4.md](call-800650b4.md).
This note stops at the branch. It does not enter either target body.

The slice contains no `jal`.

## Our code

`components/exe/call_80065098.cpp` stores `v0` at offset zero on the
record, applies the `0x80` test on complemented input, advances the table
cursor by four, and records which side the `beq` would take. Glue in
`menu_input_scan_step` calls [call-800650a8](call-800650a8.md) or
[call-800650b4](call-800650b4.md) from that result, then runs the shared bit
tails from `0x800650cc`.

## Gap

Live complemented input and `beq` sides on the measured `s6` zero path do
not state behavior when `s6` is nonzero. Retail observation of this entry
is still open in [call-80064e40.md](call-80064e40.md).
