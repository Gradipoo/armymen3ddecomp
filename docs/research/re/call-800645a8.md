# Record clear at 0x800645a8

[call-80065144.md](call-80065144.md) reaches this body when the word at
`0x800dd730` is not four. `python3 tools/sdk_match.py` does not name it.
Inventory lists `FUN_800645a8` at address `0x800645a8`, size `0x3c`.

The callee clears one record slot selected by `a0` (`s5`). Base pointer math
uses `0x800dd748` (`0x800e0000 - 0x28b8`). Stride is 124 bytes per index.

## Our code

`call_800645a8` zeros the first `0x15` bytes of the selected host slot when
`slots_base` and stride are provided. With no buffer, it is a documented
no-op. This does not model retail RAM at `0x800dd748`.
