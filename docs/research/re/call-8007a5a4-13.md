# Return at 0x8007a5a4 and the repeated cursors

Traced fact from the USA PS-X EXE. Re-check on a disc you own with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x8007a5a4`. The executable and the listing stay in `build/`.

The start address is `0x8007a5a4`. The `jr` in [call-8007a4e4-13.md](call-8007a4e4-13.md) returns here. `v0` is `0x800b3b68`. `s0` is `0x800b3b78`. `s1` is 1. `s2` is `0x80010018`. `s3` is 0. `s4` is `0x8001007c`. The frame at `0x800251f8` stays open. Its saved `ra` stays `0x8007faec`.

The word at `0x800b3b70` is 0, so `s1` becomes 0. The word at `0x800b3b7c` is `0x80076500`, so control returns to `0x8007a590` and the `beq` there is taken. `s3` stays 0. `s2` becomes `0x8001001c`.

The cursor at `0x8001001c` is the same state as [call-8007a570-11.md](call-8007a570-11.md). The search result is [call-8007a4e4-11.md](call-8007a4e4-11.md). The return is [call-8007a5a4-11.md](call-8007a5a4-11.md), so `s2` becomes `0x80010020`. The cursor at `0x80010020` is the same state as [call-8007a570-12.md](call-8007a570-12.md). The search result is [call-8007a4e4-12.md](call-8007a4e4-12.md). The return is [call-8007a5a4-12.md](call-8007a5a4-12.md), so `s2` becomes `0x80010024`. `a1` is `0x80010064` and `a2` is `0x800b5da0` after that search. This note does not disassemble `0x8007a4e4` again.

The live word at `0x80010024` is `0x800b3b68`, which those notes do not use. The next lap is the next note. The caller return at `0x8007faec` is not traced.
