# Resume at 0x80010e24

`0x80010e24` is the instruction after the `jal` in [call-80010e00.md](call-80010e00.md). [call-8007a3bc.md](call-8007a3bc.md) returns here with `v0` as 1.

`lw` loads the saved `ra`. `jr ra` returns through it. The delay adds `0x18` to `sp`. The saved `ra` is the `ra` that entered `0x80010e00`. That value is not stated. `v0` stays 1.

The four words `lw ra`, `nop`, `jr ra`, and `addiu sp, sp, 0x18` occur at many addresses. This note covers only `0x80010e24`.

## Our code

`call_80010e24` returns the value already in `v0`. The host check expects 1.

## Gap

The saved `ra` is not stated. This note does not resume the caller of `0x80010e00`.
