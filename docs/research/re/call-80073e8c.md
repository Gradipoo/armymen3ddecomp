# Call at 0x80073e8c

No traced entry reaches this address. `v0` becomes `0x800e1508`. `s0` loads `0x800e1530`. That address is inside the zero fill in [entry-after-fill.md](entry-after-fill.md). No traced note stores it, so `s0` is 0. `a1` keeps the high bits of the arriving `a1` by masking with `-0x800`. The arriving `a0` and `a1` are not stated.

`sw` stores `a0` at `0x800e1530` and the masked `a1` at `0x800e1534`. `jal` at `0x80073eb0` targets `0x80073e70`. [call-80073e70.md](call-80073e70.md) names that body. `ra` is `0x80073eb8`. This note does not enter that body.

The epilogue copies the old `s0` into `v0`, so `v0` is 0. `jr ra` returns through the arriving `ra`. This note does not state that address.

The 64 bytes from `0x80073e8c` through `0x80073ec8` occur once.

## Our code
