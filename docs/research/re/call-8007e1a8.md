# Call at 0x8007e1a8

No traced entry reaches this address. `lw` reads `0x800e19f0`. [call-8007e17c.md](call-8007e17c.md) stores `0x8000` there, and later notes leave that word as `0x8000`. `jr ra` returns `0x8000`. The arriving `ra` is not stated.

The 16 bytes from `0x8007e1a8` through `0x8007e1b4` occur once.

## Our code

`call_8007e1a8` returns the word. The host check expects `0x8000`.

## Gap

This boot does not reach `0x8007e1a8`.
