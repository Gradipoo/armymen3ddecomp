# Call at 0x800818cc

Traced fact from the USA PS-X EXE. Re-check on a disc you own with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x800818cc`. The executable and the listing stay in `build/`.

The start address is `0x800818cc`. The `jal` in [call-8005c1d4.md](call-8005c1d4.md) jumps here. `ra` is `0x8005c1e8`. `s0` is 1. `s1` is `0x800e54e0`.

`lui` at `0x800818cc` sets `v0` to `0x800b0000`. `lbu` at `0x800818d0` loads the byte at `0x800b5fcc` into `v0`. This note does not state that byte. `jr` at `0x800818d4` returns through `ra`. The delay slot is `nop`. Control goes to `0x8005c1e8`. The cited value is in the next note.
