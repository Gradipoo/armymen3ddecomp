# Return after cursor 0x8001004c

Traced fact from the USA PS-X EXE. Re-check on a disc you own with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x8007a5a4`. The executable and the listing stay in `build/`.

The start address is `0x8007a5a4`. The `jal` in [call-8007a570-33.md](call-8007a570-33.md) returns here through [call-8007a4e4-12.md](call-8007a4e4-12.md). `v0` is `0x800b5da0`. `s0` is `0x800b5d24`. `s1` is 1. `s2` is `0x8001004c`. `s3` is 0. `a1` is `0x80010064` and `a2` is `0x800b5da0`. The frame at `0x800251f8` stays open. Its saved `ra` stays `0x8007faec`.

The word at `0x800b5da8` is 0, so `s1` becomes 0. The word at `0x800b5d28` is `0x8007c304`, so control returns to `0x8007a590` and the `beq` there is taken. `s3` stays 0. `s2` becomes `0x80010050`. That value is below `s4`, so `beq` at `0x8007a5fc` is taken.

Control goes to `0x8007a570` with `s2` at `0x80010050`. That lap is the next note. The caller return at `0x8007faec` is not traced.
