# Block at 0x80086cd0

Traced fact from the USA PS-X EXE. Re-check on a disc you own with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x80086cd0`. The executable and the listing stay in `build/`.

The start address is `0x80086cd0`. The `jal` in [call-80086cc0.md](call-80086cc0.md) calls `0x8007f598` and returns here. This note does not enter that body, so it does not quote the arriving `v0`. `s1` is `0x800e15f0`. `sp` is `0x80010bac`. The slot at `0x10(sp)` is `0x800e15f0`. The slot at `0x14(sp)` is `0x800e15b0`. The slot at `0x18(sp)` is 0. The slot at `0x1c(sp)` is `0x80076220`. There is no conditional branch and no `jal`. The hard cap is 64 instructions. This block ends at `jr ra` before the cap.

`addu` copies `s1` into `v0`, so `v0` is `0x800e15f0`. `lw` loads `0x80076220` from `0x1c(sp)` into `ra`. `lw` loads 0 from `0x18(sp)` into `s2`. `lw` loads `0x800e15b0` from `0x14(sp)` into `s1`. `lw` loads `0x800e15f0` from `0x10(sp)` into `s0`. `jr` returns through `ra`. The delay slot adds `0x20` to `sp`, so `sp` becomes `0x80010bcc`.

After the delay slot, control goes to `0x80076220`. [call-800761dc.md](call-800761dc.md) already follows that address. `v0` is `0x800e15f0`. `s0` is `0x800e15f0`. `s1` is `0x800e15b0`. `s2` is 0. `ra` is `0x80076220`. The display x and y halfwords are still not quoted. This note does not close the gap in `components/exe/load.cpp`.
