# Call at 0x8007f040

No traced entry reaches this address. `v0` is `0x800e0000`. `jr ra` returns that value. The delay stores `a0` at `0x800e1bac`. That address is inside the zero fill in [entry-after-fill.md](entry-after-fill.md). `a0` is not stated. The arriving `ra` is not stated.

The 12 bytes from `0x8007f040` through `0x8007f048` occur once.

## Our code

`call_8007f040` returns `0x800e0000` and keeps the stored value. The host check uses 0.
