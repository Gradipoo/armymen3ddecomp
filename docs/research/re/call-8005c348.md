# Call at 0x8005c348

Traced fact from the USA PS-X EXE. Re-check on a disc you own with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x8005c348`. The executable and the listing stay in `build/`.

The start address is `0x8005c348`. [call-8005c370.md](call-8005c370.md) reaches this compare. The name bytes are `DATA`. None of them is `0x2e` or `0x3b`, so the copy stores four bytes and the loop ends. `a2` is 4. `a3` is 0.

`jal` at `0x8005c3b8` targets `0x80076508`. `ra` becomes `0x8005c3c0`. The delay stores 0 after those four bytes. The bytes at `sp+0x10` are `DATA`. The earlier notes at `0x80076508` stay. The next note is this arrival.
