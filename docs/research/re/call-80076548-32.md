# Arrival 32 at 0x80076548

Traced fact from the USA PS-X EXE. Re-check on a disc you own with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x80076548`. The executable and the listing stay in `build/`.

The start address is `0x80076548`. The `jal` in [call-80076548-31.md](call-80076548-31.md) returns here. `a0` was `0x2e`. The byte at `0x800b5e87` is `0x10`, so bit 0 is clear and `v0` stays `0x2e`. The word at `0x800b5c10` is `0x24dd`. `s2` becomes `0xf5239c08`. `s0` becomes 8. The next byte is `0x49`.

`jal` at `0x80076540` calls `tolower` with `a0` `0x49`. This note does not enter `tolower`. The return is the next note.
