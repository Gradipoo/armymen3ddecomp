# Block at 0x8005ca30

This is the other side of `bne` at `0x8005ca28` in [call-8005ca00.md](call-8005ca00.md). That note takes the branch. For `legal.bg` the first byte becomes `0x4c`. For `\mission.ini` it stays `0x5c`. Neither is `0x43`. This boot does not reach `0x8005ca30`, and the cited strings do not either.

If this side ran, `lb` at `0x8005ca30` would load the second byte. That byte is `0x65` in `legal.bg` and `0x6d` in `\mission.ini`. `jal` at `0x8005ca34` targets `toupper` at `0x8007ff4c`. This note does not enter that body. `toupper` returns `0x45` for `0x65` and `0x4d` for `0x6d`. The delay is `nop`.

`a3` is `0x44`. Neither result matches, so `bne` at `0x8005ca48` is taken. The delay sets `v0` to `s0`, the buffer. The epilogue at `0x8005ca68` returns to `0x8005cc88`. `v0` is the buffer.

The 32 bytes from `0x8005ca30` through `0x8005ca4c` occur once.

## Our code

`call_8005ca30` returns the buffer when `toupper` of the second byte is not `D`. `toupper` now returns `E` for `e` and `M` for `m`. The host check uses both cited strings.

## Gap

The compare with `0x44` is not taken for these strings. This boot does not reach `0x8005ca30`.
