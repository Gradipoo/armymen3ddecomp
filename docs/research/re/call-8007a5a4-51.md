# Return at 0x8007a5a4 and the repeated cursors

Traced fact from the USA PS-X EXE. Re-check on a disc you own with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x8007a5a4`. The executable and the listing stay in `build/`.

The start address is `0x8007a5a4`. The `jal` in [call-8007a540-17.md](call-8007a540-17.md) returns here through [call-8007a4e4-14.md](call-8007a4e4-14.md). `v0` is `0x800b3b68`. `s2` is `0x80010040`. `s3` is 0. `s4` is `0x8001007c`. The frame at `0x800251f8` stays open. Its saved `ra` stays `0x8007faec`.

The return matches [call-8007a5a4-47.md](call-8007a5a4-47.md), so `s2` becomes `0x80010044`. Cursor `0x80010044` matches [call-8007a570-44.md](call-8007a570-44.md) and [call-8007a5a4-48.md](call-8007a5a4-48.md), so `s2` becomes `0x80010048`. This note does not disassemble `0x8007a4e4` again.

The live word at `0x80010048` is `0x800b599c`, from [call-8007a668-16.md](call-8007a668-16.md). [call-8007a570-45.md](call-8007a570-45.md) saw `0x800b5d14` there. The next lap is the next note. The caller return at `0x8007faec` is not traced.
