# Call at 0x800741b8

[call-800746a4.md](call-800746a4.md) calls here. `a0` is 2. `ra` is `0x80074750`. This boot does not reach this address.

`andi` leaves `a0` as 2. `beq` at `0x800741c4` is taken. The delay saves `ra`. The increment at `0x800741dc` is not this side.

`t0` becomes `0x800e1508`. `a1` loads `0x800e1550`, which is 0. `t1` loads `0x800e1564`, which is 0. `a2` loads `0x800e1568`. The previous note stored 0 there, so `a2` is 0. `ori` sets bit 2 of `0x800e152c`, so that word becomes 4 on this side. `and` with `-0x81` leaves 4. The three `sw` instructions store 0 at `0x800e1550`, `0x800e1554`, and `0x800e1564`. `sw` stores `a2` at `0x800e156c`, so that word is 0. This boot does not run those stores.

`beq` at `0x80074224` compares `t1` with 0 and is taken. The `jalr` is not this side. The epilogue reloads `ra` as `0x80074750`. `jr ra` returns there. `v0` stays 4.

The 148 bytes from `0x800741b8` through `0x80074248` occur once.

## Our code

`call_800741b8` returns 4 when the low byte of `a0` is 2 and the link word is 0. The host check uses those values.
