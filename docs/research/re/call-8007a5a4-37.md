# Return at 0x8007a5a4 and the repeated cursors

Traced fact from the USA PS-X EXE. Re-check on a disc you own with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x8007a5a4`. The executable and the listing stay in `build/`.

The start address is `0x8007a5a4`. The `jal` in [call-8007a540-12.md](call-8007a540-12.md) returns here through [call-8007a4e4-14.md](call-8007a4e4-14.md). `v0` is `0x800b3b68`. `s0` is `0x800b5ba8`. `s2` is `0x8001002c`. `s3` is 0. `s4` is `0x8001007c`. The frame at `0x800251f8` stays open. Its saved `ra` stays `0x8007faec`.

The return matches [call-8007a5a4-22.md](call-8007a5a4-22.md), so `s2` becomes `0x80010030`. The laps from `0x80010030` through `0x80010054` match [call-8007a570-23.md](call-8007a570-23.md) through [call-8007a5a4-34.md](call-8007a5a4-34.md). Cursor `0x80010058` matches [call-8007a570-36.md](call-8007a570-36.md) and [call-8007a5a4-36.md](call-8007a5a4-36.md), so `s2` becomes `0x8001005c`. This note does not disassemble `0x8007a4e4` again.

The live word at `0x8001005c` is `0x800b5b98`, from [call-8007a668-11.md](call-8007a668-11.md). [call-8007a570-37.md](call-8007a570-37.md) saw `0x800b5d8c` there. The next lap is the next note. The caller return at `0x8007faec` is not traced.
