# Call at 0x8007a420

Traced fact from the USA PS-X EXE. Re-check on a disc you own with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x8007a420`. The executable and the listing stay in `build/`.

The start address is `0x8007a420`. The `jalr` in [call-8007a668-9.md](call-8007a668-9.md) jumps here. `ra` is `0x8007a6bc`. `a0` is `0x80010040`. The caller `s1` is 10. The frame at `0x800251f8` stays open. Its saved `ra` stays `0x8007faec`.

`addiu` at `0x8007a420` subtracts `0x28` from `sp`. `lui` at `0x8007a424` and `addiu` at `0x8007a428` set `v0` to `0x8007f9a8`. The saves store `ra` and `s3` through `s0`. No note in this boot has stored `0x8007f9b8` or `0x8007f9bc`. The file word at `0x8007f9b8` is `0x800c5448`. The file word at `0x8007f9bc` is `0x800c5454`. `lw` at `0x8007a440` loads `s2` as `0x800c5454`. `lw` at `0x8007a444` loads `s1` as `0x800c5448`.

`0x800c5448` is below `0x800c5454`, so `sltu` sets `v0` to 1 and `beq` at `0x8007a450` is not taken. The delay slot sets `s3` to `0x800c5450`.

`lw` at `0x8007a458` loads the word at `0x800c5448`. This boot does not state that word. `beq` at `0x8007a460` compares it with 0. This note does not follow that branch. The caller return at `0x8007faec` is not traced.
