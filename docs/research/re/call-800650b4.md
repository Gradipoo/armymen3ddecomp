# Taken target at 0x800650b4

[call-80065098.md](call-80065098.md) records `beq` at `0x800650a0` when the
`0x80` bit test on complemented input is zero. The taken target is this
address. The fallthrough is `0x800650a8`. This note covers the taken path
only. It does not resume the parked static boot.

`python3 tools/boot_slice.py build/disc/SLUS_004.91 --start 0x800650b4 --max 64`
reports three instructions and stops at an unknown branch. The report stays in
`build/`.

| Address | Instruction |
| --- | --- |
| `0x800650b4` | `andi v0, a0, 0x20` |
| `0x800650b8` | `beq v0, zero, 0x800650c8` |
| `0x800650bc` | `addiu v0, zero, 0x7f` |

The delay slot at `0x800650bc` always runs and sets `v0` to `0x7f` before
the branch resolves. `beq` at `0x800650b8` compares the `0x20` bit test with
zero. The taken address is `0x800650c8`. The fallthrough is `0x800650c0`.

`python3 tools/boot_slice.py build/disc/SLUS_004.91 --start 0x800650c8 --max 64`
reports `sb zero, 0xa(s0)` at `0x800650c8`, then the same `andi` at
`0x800650cc` as [call-800650a8.md](call-800650a8.md), and stops at the
unknown `beq` at `0x800650d0`.

`python3 tools/boot_slice.py build/disc/SLUS_004.91 --start 0x800650c0 --max 64`
reports `j 0x800650cc` with delay slot `sb v0, 0xa(s0)`, so the fallthrough
stores `0x7f` at offset `0x0a` before joining `0x800650cc`.

Static boot does not state complemented input for a nonzero `s6` sample, so
the side of `beq` at `0x800650b8` is unknown for retail. Both sides through
rejoin at `0x800650cc` are stated in the slices above. This note stops at the
unknown `beq` at `0x800650d0` on the shared tail. It does not enter either
target there.

The span through `0x800650c8` and `0x800650c0` contains no `jal`.

## Our code

`components/exe/call_800650b4.cpp` applies the `0x20` test, records which
side `beq` at `0x800650b8` would take, stores zero at offset `0x0a` on the
taken path and `0x7f` on the fallthrough path, then returns. Glue calls it
after [call-80065098](call-80065098.md) when the `0x80` bit is clear, then
runs the same complemented bit tails as the `s6` zero path from `0x800650cc`.

## Gap

The shared `beq` at `0x800650d0` and later tails stay in
[call-800650d0.md](call-800650d0.md) and the sibling tail notes. Live
complemented input on the `s6` nonzero path is not stated.
