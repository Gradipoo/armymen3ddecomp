# Call at 0x8005c330

Traced fact from the USA PS-X EXE. Re-check on a disc you own with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x8005c330`. The executable and the listing stay in `build/`.

The start address is `0x8005c330`. [call-8005c334.md](call-8005c334.md) reaches this compare. The name bytes are still `COPYRITE.TXT;1`. The count is `0x0e`.

This note follows the next 64 instructions. The 64th is `beq` at `0x8005c330` again. The next instruction is its delay, `addiu` at `0x8005c334`.
