[call-8005be9c.md](call-8005be9c.md) would store 2 there, and this boot does not run that store. No other traced note stores the word, so it is 0. `andi` with 1 leaves 0. `beq` at `0x8005c030` is taken. The delay sets `v1` to 0. The `jal` at `0x8005c038` is not this side. `tools/sdk_names.txt` names that target `CdDiskReady`.

`addu` at `0x8005c04c` copies `v1` into `v0`, so `v0` is 0. `jr ra` returns to `0x800752a8`. The delay adds `0x18` to `sp`.

The 64 bytes from `0x8005c014` through `0x8005c050` occur once.
