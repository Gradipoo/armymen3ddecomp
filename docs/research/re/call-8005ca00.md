# Call at 0x8005ca00

[call-8005cc80.md](call-8005cc80.md) calls here. `a0` is `sp+0x10`, the copied buffer. For `legal.bg` the first byte is `0x6c`. For `\mission.ini` the first byte is `0x5c`. `ra` is `0x8005cc88`. The word at `0x800e152c` is 0, so this boot does not reach this address.

`addiu sp, sp, -0x18` opens a frame. `s0` becomes `a0`. The prologue saves `ra` `0x8005cc88` and `s0`. `lb` loads the first byte into `a0`.

`jal` at `0x8005ca14` targets `0x8007ff4c` and sets `ra` to `0x8005ca1c`. `tools/sdk_names.txt` names that target `toupper`. This note does not enter that body. For `0x6c`, `toupper` returns `0x4c`. For `0x5c`, it returns `0x5c`. The delay is `nop`.

`sll` and `sra` sign-extend that byte. It is not `0x43`, so `bne` at `0x8005ca28` is taken. The delay sets `v0` to `s0`, the buffer pointer. The second `toupper` call is not this path. The epilogue restores `ra` to `0x8005cc88` and `s0`. `jr ra` returns to `0x8005cc88`. `v0` is the buffer pointer.

## Our code

`toupper` returns `L` for `l` and leaves `\` unchanged. `call_8005ca00` returns the buffer when that result is not `C`. The host check uses both cited strings.
