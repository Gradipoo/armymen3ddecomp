# Call at 0x80065304

No traced entry reaches this address. `v0` is `0x800dd708`. That address is inside the zero fill in [entry-after-fill.md](entry-after-fill.md). `a0` is shifted left by 2 and added to `v0`. `sb` writes `a2` at offset 8 of that sum and `a1` at offset 9. `a0`, `a1`, and `a2` are not stated. `jr ra` returns `0x800dd708`. The arriving `ra` is not stated.

The 28 bytes from `0x80065304` through `0x8006531c` occur once.

## Our code

`call_80065304` returns `0x800dd708` and writes the two bytes. The host check uses index 0 and bytes 1 and 2.
