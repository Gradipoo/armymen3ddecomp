# Call at 0x80011cc0

No traced entry reaches this address. `lbu` reads the byte at `a0+0x20`. `sb` writes 0 at `a0+0x21`. `ori` sets bit 2 of the loaded byte. `jr ra` returns that value. The delay stores it back at `a0+0x20`.

`a0` is not stated. The arriving `ra` is not stated.

The 20 bytes from `0x80011cc0` through `0x80011cd0` occur once.

## Our code

`call_80011cc0` sets bit 2 and clears the next byte. The host check starts the byte at 1 and expects 5.
