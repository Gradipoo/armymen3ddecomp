## Our code

`components/exe/call_8007a2b0.cpp` updates the words at offsets `0x14`,
`0x18`, and `0x1c`, and writes the stack slot. A zero word at offset
`0x1c` returns `0`. A nonzero word returns `1` and follows the link
rules above. A host check uses the arrival values and local values for
the other sides. The check uses a local load. It does not run a retail
