# Call at 0x8005c338

Traced fact from the USA PS-X EXE. Re-check on a disc you own with `python3 tools/entry_disasm.py build/disc/SLUS_004.91 --start 0x8005c338`. The executable and the listing stay in `build/`.

The start address is `0x8005c338`. [call-8005c334-3.md](call-8005c334-3.md) reaches this compare. The counted bytes are `MISSION.INI;1`. The byte `0x2e` sets `t2` to 1. The byte `0x3b` ends the copy, so the final `1` is not stored. `a2` is 8. `a3` is 3.

`jal` at `0x8005c3b8` targets `0x80076508`. `ra` becomes `0x8005c3c0`. The delay stores 0 after the copied bytes. The bytes at `sp+0x10` are `MISSION.INI`. The earlier notes at `0x80076508` stay. The next note is this arrival.
