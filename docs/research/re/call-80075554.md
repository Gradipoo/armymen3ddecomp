# Call at 0x80075554

No traced entry reaches this address. `s0` is `0x800e1588`. `lw` at `0x80075570` reads `0x800e1594` into `a0`. That address is inside the zero fill in [entry-after-fill.md](entry-after-fill.md). [call-80075440.md](call-80075440.md) would store there, and this boot does not run it, so `a0` is 0.

`jal` at `0x80075574` targets `0x8008151c`. `tools/sdk_names.txt` names that target `CdGetToc`. `ra` is `0x8007557c`. The delay is `nop`. This note does not enter that body. `addu` copies the return into `v1`. That `v0` is not stated. `blez` at `0x80075580` is not followed.

The 52 bytes from `0x80075554` through `0x80075584` occur once.

## Our code
